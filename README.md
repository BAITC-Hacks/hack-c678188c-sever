# hack-c678188c-sever

Репозиторий команды **Sever**. Трек 03, репетиция HackAlem: FAQ-бот на 5 вопросов.

Терминальный чат читает `faq.txt` и отвечает на ближайший вопрос по ключевым словам. Если похожего нет — пишет «не знаю». RAG и внешние API не используются.

## Как запустить

Нужен Python 3.10+ (стандартная библиотека, зависимости не ставятся).

```bash
python3 bot.py
```

Пишите вопрос в терминале. Выход: `выход`, `quit` или `exit`.

Примеры:

```
Вы: сколько времени на задание?
Бот: Репетиция — лёгкий кейс, не основной HackAlem AI. На скрипт хватит 30–60 минут...

Вы: будут призы?
Бот: Призов нет. Это репетиция, не основной HackAlem AI.

Вы: какая погода в Астане?
Бот: не знаю
```

## Что получилось

- `faq.txt` — пять пар вопрос–ответ про репетицию: время, команда, трек, сдача, призы.
- `bot.py` — чат в терминале: совпадение по ключевым словам (покрытие токенов вопроса), иначе «не знаю».
- Стек любой по условию; здесь один короткий Python-скрипт без библиотек.
